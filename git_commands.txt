# Git Commands for your project

# This file is for your notes and is not used by the app.

## To save your changes to GitHub:
# 1. Stage your changes
git add .

# 2. Commit your changes with a message
git commit -m "Type your text here"

# 3. Push your changes to GitHub
git push origin main


## To get the latest changes from GitHub:
git pull origin main

## To see the status of your changes:
git status

## To restore from GitHub
git restore .
git clean -fd

## RELEASE PROCEDURE (IMPORTANT FOR F-DROID)
# To ensure the APK matches the source code hash:

# 1. COMMIT ALL CHANGES
git add .
git commit -m "v1.9.2: Uniform dialog graphics, sync bugfixes and F-Droid safety cleanup."

# 2. CREATE AND PUSH TAG
git tag v1.9.2
git push origin main
git push origin --tags

# 3. BUILD APK NOW
# Only now, generate the Signed APK from Android Studio.
# This ensures the Git Revision embedded in the APK matches the tag.

# 4. UPLOAD TO GITHUB
# Go to GitHub, create a Release for tag v1.9.2 and upload 'app-release.apk'.
